# 知识演进可观测控制台

知识详情由 Sidecar 在读取时组合：Registry 提供不可变知识版本，Freshness Store 提供同版本的锚点、当前状态和状态事件。两者不会相互覆盖。

默认召回资格同时受两类门禁约束：治理门禁判断版本、状态、证据与 suppress；代码知识门禁要求保鲜投影存在且状态为 `FRESH`。缺失投影会明确展示为“尚未建立保鲜投影”，不会误报为新鲜。

页面展示代码路径、符号、配置与依赖锚点，并按倒序展示不可变状态事件。中文用于理解，原始诊断码用于检索日志和问题定位。

安全边界：详情、锚点和历史查询只读；修改、移除和恢复继续使用 expected-version、幂等键和新版本发布，不提供物理删除。

会话提取页同时读取同一 Worker checkpoint 中的候选正文、可执行断言、用户承诺、歧义和演进决策，避免只看到“新增数量”却无法判断将发布什么。所有字段均有条数和字节上限，超长展示值只在 Console 投影中截断，不修改原始 checkpoint。

注入页提供独立的 `context.refresh(sessionId)` 控制命令。命令只清除该会话的 L1 稳定目录缓存，下一轮 Prompt 再按当前 Registry/Policy/Scope 预热；它不会写入 Codex 对话或 Ledger。Gateway 继续强制 loopback、浏览器会话、Origin 和 CSRF，Sidecar 对幂等键返回稳定回执并拒绝跨会话复用。
